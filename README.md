# Praxis fuer Psychotherapie

This is a static website that can be published directly with GitHub Pages or any static web host.

## Edit content

1. Open `editor.html` in the browser.
2. In Chrome or Edge on the deployed HTTPS site, select or drop `content.js` once with **content.js verbinden**. The editor loads that file as the draft. Update the fields and use the visual text controls where needed. The editor keeps an automatic local draft in the browser.
3. Click **In content.js speichern** to write back to the chosen local file, then commit and push it. The browser must ask the user to choose the file; a website cannot access a repository file silently.
4. In other browsers, use the generated `content.js` download instead.

`content.js` is generated by the editor and should not be edited directly.

## Replace images

- The portrait in the opening section uses `therapist.png` in a tall 3:4 crop.
- The office section currently shows an intentionally labelled placeholder. Replace it with a calm, well-lit landscape image (at least 1600 x 1050 px) once photography is available.

## Visual settings

All colour tokens are defined at the top of `index.html` in the `:root` block. The wine-red palette can be changed there without touching the component styles.
