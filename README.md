# Praxis fuer Psychotherapie

This is a static website that can be published directly with GitHub Pages or any static web host.

## Edit content

1. Open `content.js` in a text editor.
2. Replace the example name, contact details, costs, copy, and OpenStreetMap link with the practice details.
3. Commit and push the edited files. No build step is required.

## Replace images

- The portrait in the opening section uses `therapist.png` in a tall 3:4 crop.
- The office section currently shows an intentionally labelled placeholder. Replace it with a calm, well-lit landscape image (at least 1600 x 1050 px) once photography is available.

## Visual settings

All colour tokens are defined at the top of `index.html` in the `:root` block. The wine-red palette can be changed there without touching the component styles.
