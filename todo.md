## 10. Technische SEO vor dem Launch

- [ ] Wesentliche Inhalte bereits im ausgelieferten HTML bereitstellen (Static Rendering/Pre-Rendering) und nicht ausschließlich nachträglich per JavaScript einsetzen.
- [ ] Für jede indexierbare Seite einen eindeutigen, aussagekräftigen `<title>` erstellen.
- [ ] Für jede indexierbare Seite eine passende Meta-Description erstellen.
- [ ] Pro Seite genau eine klare Hauptüberschrift und eine logische Überschriftenstruktur verwenden.
- [ ] Aussagekräftige, stabile URLs verwenden.
- [ ] Canonical-URL auf jeder indexierbaren Seite ergänzen.
- [ ] `robots.txt` erstellen und prüfen.
- [ ] XML-Sitemap erstellen und automatisiert aktuell halten.
- [ ] Editor, Staging, interne Vorschauen und Duplikate von der Indexierung ausschließen.
- [ ] Open-Graph- und Social-Sharing-Metadaten ergänzen.
- [ ] Strukturierte Daten als JSON-LD ergänzen, beispielsweise `LocalBusiness` oder einen passenden `MedicalBusiness`-Typ.
- [ ] In strukturierten Daten nur korrekte Angaben zu Name, URL, Telefon, Adresse, Bild/Logo, Standort und Öffnungszeiten verwenden.
- [ ] Nicht den Typ `Physician` verwenden, sofern diese Berufsbezeichnung nicht tatsächlich zutrifft.
- [ ] Strukturierte Daten mit Googles Rich Results Test validieren.
- [ ] Weiterleitungen für später geänderte URLs einrichten.
